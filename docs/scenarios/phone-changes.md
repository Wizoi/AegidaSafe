## Galaxy Store (findings #106, reviewed Oct 14)

Real data: on a Galaxy S25 (One UI 8.0) every Galaxy Store app recorded installer and initiating installer `com.sec.android.app.samsungapps` (3 of 3), and Galaxy Store is a SYSTEM, PRIVILEGED, updated system app. On Kevin's Pixel 11: 186 apps from Play, 2 Chrome web apps (installer `com.android.chrome`), none from anything else. Design (after the Opus review): `OemSource.appStores()` names the maker's own store (Galaxy Store on a Samsung, nothing elsewhere); the snapshotter keeps only stores that are system apps in the same app list and puts them in `Snapshot.makerStores`; an app counts as from that store only when both its installing and its initiating installer (`InstallSourceInfo`, Android 11+) are that store. Only the new-app question uses it: the spying-app check (R18), remote-control check and access checks are unchanged. Remote-control apps on the Galaxy Store (checked Oct 14): AnyDesk and both TeamViewer apps use the same package names as on Play; RustDesk, AirDroid, Splashtop SOS and TeamViewer Host are not listed there.

## History: a later line closes an earlier one (findings #129, Kevin, Oct 14)

Kevin's decision (option B): when a warning or question closes, its earlier amber History row for the same problem and the same app or
site turns green. Data: History keeps only (time, problem, outcome, detail) and the screen groups entries by (time, problem, detail); the
detail is written by `HistoryDetail` from the finding's evidence (the app's name, the website, the message), and the urgent kinds never
carry the app's name (R17), so their detail is empty. Design: every closing line (Fixed, "No longer a concern.", "You saw it." after
Got it / Yes, and the new "See the newer warning.") is written with the same detail as the warning, made by `HistoryDetail` from the
finding as it was stored. On the History screen an amber row turns green when a closing line of the same problem with exactly the same
detail was written after it. A line with no detail closes an earlier row only for the kinds there is one of at a time (website
protection, notice access, notifications blocked, guardian unreachable, lists old); for every other kind, and so for every urgent kind,
it closes nothing. No Room migration (the closing line uses the existing detail column) and nothing new is sent to the guardian.
