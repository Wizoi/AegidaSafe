# Ideas (not built, not promised)

Things that were considered at some point. None of them is in the app, and listing one here is not a promise that it
will be. What the app does today is in [product-brief.md](product-brief.md).

- A second guardian, told only if a warning is still open a day after the first guardian was told.
- A guardian "Got it" reply (an ntfy action button) that marks a warning as seen.
- Asking Play Protect (Play Integrity) for its verdict on installed apps.
- Google Safe Browsing lookups for links in messages.
- MalwareBazaar and URLhaus in the scam list (URLhaus is held back until abuse.ch allows republishing).
- Matching installed apps by APK hash as well as package name and signing certificate.
- Noticing a new app the moment it is installed (today it is noticed at the next check).
- A setup step for Samsung's "Never sleeping" list, and reading whether Aegida is on it.
- Telling the guardian at the end of setup if the owner chose "Not now" for Samsung Auto Blocker.
- A weekly digest for the guardian.
- A manual "Check this" share target for a link or message.
- A warning for remote-access apps combined with banking apps (needs Usage Access).
- Opt-in call screening.
- Letting the owner choose apps whose notices Aegida hides.
- An observe-only first release (no hiding, few banners) for a new phone.
- An opt-in support log a guardian could read.
- Emulator scenarios run nightly in CI.
